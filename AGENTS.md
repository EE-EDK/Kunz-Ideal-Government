# Ideal Government — AGENTS.md

Startup brief for any agent working in this repo.

1. Read `README.md` and `CLAUDE.md`.
2. The design lives in `data/layers.json`. The HTML is generated — regenerate it, don't hand-edit.
3. Run `python3 src/build_ideal_government.py --check` before committing data changes.
4. Commit and push to `origin main` when a change is complete. Commit messages carry no attribution trailers (the workspace `commit-msg` hook rejects them).
5. The page is published publicly at `/p/ideal-government/` under the owner-approved exception in `CLAUDE.md`. Do not publish it anywhere else without the owner's say-so.
